首頁與明細頁均提供繁體中文／Bahasa Indonesia 按鈕，記住本機語言選擇。repair_id.json 僅由已公開去識別資料翻譯，包含全部 893 筆案件的修繕內容、備註及工種，涵蓋 874 種描述、222 種備註、16 種工種。雙語功能保留原始中文、案件編號、樓層、完成日期及狀態計數；新增戶號的查核時間另見下段。翻譯保留原有換行與遮除標記，不使用外部翻譯服務。來源更新時必須同步補足譯文，不得用中文原文冒充印尼文翻譯。翻譯供閱讀參考，修繕判定可切回中文核對。

明細新增棟別欄，可查看全部棟別，並組合棟別、樓層、工種（含未指定）、狀態及雙語全文搜尋。清除篩選返回全部明細。手機寬度不超過 760px 時，每筆表格列以附欄位名稱的卡片顯示，保留完整內容。首頁五個總計框分別連至全部明細或指定狀態，例：details.html?view=all&status=open。status 參數可使用 open、working、completed、needs_review。各棟狀態以圓餅圖呈現，旁列四種狀態件數，整張卡片仍可開啟該棟明細。

功能以唯讀操作驗證，未向正式來源寫入測試資料。手機尺寸的瀏覽器視窗檢查不等於手機實機或使用者人工驗收。

更新採人工提交，沒有自動拉取來源或定時同步。不要求任何憑證。Pages 使用 main 分支根目錄發布。
